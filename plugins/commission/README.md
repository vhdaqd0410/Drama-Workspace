# 🎬 AI后期剪辑提成表生成工具 v8.0

一键将 AI 项目分配表转换为完整的提成表，自动计算绩效、超额、缺集扣除和提成合计。内置可视化仪表盘、智能分集、绩效卡片、批量处理等十余项扩展功能。

## ✨ 功能一览

| 功能 | 说明 |
|---|---|
| 📊 **自动解析** | 从项目分配表中提取人员、集数、交付日期 |
| 🧮 **智能计算** | 一卡/二卡/组长提成自动计算（基准 70/120 集） |
| 📄 **生成 Excel** | 完整提成表（格式与模板完全一致，提成合计附算式） |
| 📈 **统计简报** | Excel Sheet2 月度汇总 |
| 🌐 **可视化仪表盘** | 纯静态 HTML，含集数完成 & 提成排行 CSS 柱状图、目标进度条 |
| 📐 **智能分集** | 按角色权重五段式自动分配集数，支持逐人区间编辑与人员模板 |
| 🃏 **个人绩效卡片** | 每人独立 HTML 卡片，含集数达标提成 |
| 🎯 **月度目标** | 为每人设定集数/收入目标，仪表盘显示完成进度 |
| 👥 **角色管理器** | 可视化增删改人员角色 |
| 🏆 **组内排名** | 生成月度集数/提成排行 HTML |
| 🗂 **项目管理** | 按交付日期排序的项目清单视图 |
| 📊 **月份/多组对比** | 对比两个月度或两个组的集数与提成差异 |
| 📦 **批量处理** | 多选数据文件批量生成提成表 |
| 💾 **多格式导出** | 导出人员提成/项目明细为 CSV 与 JSON |
| 📥 **数据导入** | 从 CSV/Excel 预览并导入数据 |
| 🔍 **全局搜索** | 按项目 ID / 名称 / 人员搜索定位记录 |
| 📈 **统计图表** | matplotlib 可视化收入趋势、集数柱状、项目分布 |
| ✏️ **数据修正** | 双击修正集数，支持 Ctrl+Z 撤销/重做 |
| 🎨 **主题切换** | 亮色/暗色界面主题 |
| ⚡ **快捷键体系** | Ctrl+G 生成、Ctrl+P 预览、Ctrl+D 分集、F5 刷新等 |
| 🆕 **更新检查** | 启动时检查版本更新 |

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install pandas openpyxl matplotlib
```

> `tkinter` 为 Python 标准库（Windows 下已内置）。

### 2. 配置角色

首次使用请先创建配置文件：

```bash
copy config.example.json config.json
```

然后在 GUI 中点击 **"⚙️ 角色配置"** 添加人员并设置角色，或直接编辑 `config.json`。

### 3. 启动

- 双击 **`启动工具.vbs`**（推荐，无黑窗）
- 或在终端运行：`python ai_commission_gui.py`

### 4. 使用

```
双击启动 → 检查文件 ✅ → 点击"角色配置"设置角色
→ 选择项目文件/模板 → 点击"一键生成"
→ Excel + HTML仪表盘自动打开
```

> 💡 `config.json` 与项目数据文件（`data/*.xlsx`）包含真实人员姓名和项目数据，**已被 .gitignore 排除，不会提交到仓库**。请使用 `config.example.json` 作为配置模板。

## ⚙️ 角色与提成规则

通过 GUI 中的 **"⚙️ 角色配置"** 或在 `config.json` 中编辑：

```json
{
  "人员角色": {
    "王小明": "一卡剪辑",
    "李小红": "二卡剪辑",
    "张大星": "剪辑组长"
  }
}
```

### 角色标准

| 角色 | 基准集数 | 超额 | 缺集扣除 | 其他 |
|---|---|---|---|---|
| 🟢 一卡剪辑 | **70集/月** | +20元/集 | -50元/集 | — |
| 🔵 二卡剪辑 | **120集/月** | +20元/集 | -50元/集 | — |
| 🟣 剪辑助理 | **120集/月** | +20元/集 | -50元/集 | — |
| 🟠 剪辑组长 | **无限制** | — | — | 组内每部+100元 |

### 提成计算规则

- **一卡/二卡/助理**：超出基准 × 20元 = 提成；不足基准 × 50元 = 扣除
- **组长**：总集数 × 20元 + 全组去重项目数 × 100元
- 生成的 Excel 中"提成合计"栏会显示计算过程（如 `(150-70)×20=1600`）

## 📂 项目结构

```
├── ai_commission_gui.py          # GUI 主程序
├── src/
│   ├── generate_commission.py    # CLI 核心引擎（提成计算、Excel 生成、HTML 仪表盘）

│   ├── config_loader.py          # 配置加载与校验
│   ├── models.py                 # 数据模型（dataclass）
│   ├── constants.py              # 角色常量与默认配额
│   └── utils.py                  # 共享工具函数
├── tests/                        # 回归测试
├── config.example.json           # 配置示例模板（不含真实数据）
├── 启动工具.vbs                   # 无黑窗启动器
├── install.bat                   # 一键安装依赖
├── .gitignore
└── README.md
```

> `config.json`、`data/*.xlsx`、`output/`、`backup/`、`个人绩效卡片/` 等含真实数据或产出文件的目录已被 `.gitignore` 排除，不会提交。

## 🔧 高级用法

### CLI 命令行

```bash
# 默认文件
python src/generate_commission.py

# 指定文件
python src/generate_commission.py 项目数据.xlsx 模板文件.xlsx 输出目录
```

### 自定义规则

编辑 `config.json` 中的 `rules`，可修改基准集数、超额单价等。

### 快捷键

| 快捷键 | 功能 |
|---|---|
| Ctrl+G | 一键生成 |
| Ctrl+P | 数据预览 |
| Ctrl+D | 智能分集 |
| Ctrl+S | 数据修正 |
| Ctrl+R | 角色配置 |
| Ctrl+O | 打开输出目录 |
| Ctrl+M | 月份对比 |
| Ctrl+F | 聚焦搜索 |
| F5 | 刷新角色标签 |
